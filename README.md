# Maven Java Project

## Overview
A simple Java application demonstrating the Apache Maven build lifecycle.

## Technologies
- Java 17
- Apache Maven
- JUnit 4.13.2

## Maven Lifecycle Commands
- `mvn compile` — Compiles the Java source code.
- `mvn test` — Runs unit tests.
- `mvn package` — Packages the application into a JAR file.
- `mvn clean` — Removes generated build files.

## Run the Application
```bash
java -cp target/maven-java-project-1.0-SNAPSHOT.jar com.careertiq.app.App
```

## Expected Output
```text
Hello World!
```
